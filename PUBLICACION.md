# Publicar la web de Nexus Enterprise

El proyecto es estático: HTML + CSS + JavaScript + imágenes.

## Opción simple
Sube **todo el contenido de esta carpeta** al directorio público de tu hosting y configura `index.html` como página inicial.

## Estructura mínima que debe publicarse
- Todos los `.html`
- Carpeta `assets/`
- `site.webmanifest`
- `robots.txt`

## Antes de producción
- Configura el dominio real.
- Verifica el enlace MediaFire del Setup.
- Sustituye los wordmarks de clientes por logos oficiales autorizados cuando los tengas.
- Si conectas el Portal o formularios a un backend, actualiza privacidad y términos.
- Configura HTTPS.
- Agrega analítica solo si decides usarla y refleja su uso en la política de privacidad.
