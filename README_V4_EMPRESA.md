## Importante sobre logos de clientes
Los archivos en `assets/clients/` son *wordmarks tipográficos locales* creados para presentar los nombres de las marcas sin depender de recursos externos. Si se dispone de los logos oficiales autorizados de Daca Sport, Rican2 Sport, La Cabra Store y Novaro Venezuela, deben sustituirse por esos archivos manteniendo los mismos nombres/rutas.

## Publicación
Esta versión es estática. Se puede publicar en hosting tradicional, Cloudflare Pages, GitHub Pages, Netlify, Vercel Static o un servidor propio.

Antes de publicar:
1. Sustituir el dominio en metadatos futuros si se agrega sitemap.
2. Conectar formularios a backend si se desea almacenar leads; actualmente el cotizador abre WhatsApp.
3. Revisar jurídicamente `terminos.html` y `privacidad.html` antes de comercialización amplia.
4. Sustituir wordmarks de clientes por logos oficiales si están disponibles.
5. Probar el enlace de descarga y actualizar la versión cuando cambie el Setup.
